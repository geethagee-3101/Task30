# Task 30 – Simple Inventory Tracker

## Objective
Created an Excel-based inventory tracker to monitor stock quantities, reorder levels, and stock status.

## Tools Used
- Microsoft Excel
- IF Formula
- Conditional Formatting

## Features
- Tracks item names and stock quantities.
- Automatically identifies low-stock items.
- Highlights reorder items.
- Generates a low-stock report.
- Calculates suggested reorder quantities.

## Outcome
Successfully created an inventory tracking system that helps monitor stock and identify items requiring restocking.
